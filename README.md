
# 👱 Sebastian Cacean's Personal Webpage

This repo contains my personal webpage. It is is built with [Quarto](https://quarto.org/) and based on ideas from my [argdown-quarto-pdf-template](https://github.com/xylomorph/argdown-quarto-pdf-template) and my [quarto-course-template](https://github.com/xylomorph/quarto-course-template).

## 🚀 Local Development/Testing & Deployment

1. Fork, clone or download
2. `cd` into the root folder
3. Install needed Quarto extensions, R packages and Node dependencies (see below)
4. Run `make render` to render the website
5. Check with `make preview`
6. Push to GitHub to deploy

## 🔧 Technical Details

+ Quarto with the following extensions:
    + <https://github.com/schochastics/academicons>
    + <https://github.com/quarto-ext/fontawesome> (icons)

### Multilang Support with BabelQuarto

This website uses the [`babelquarto`](https://github.com/expersso/babelquarto) R package for multilingual site generation.

**Workflow:**

1. Base files (e.g., `index.qmd`) contain the primary content
2. Language-specific files (e.g., `index.de.qmd`) contain translations
3. Missing translations are auto-generated by copying the base file (useful during development)
4. `render_website()` renders the complete multilingual site

**Usage:**

```bash
# Install R dependencies
Rscript myblog/scripts/install-r-packages.R

# Render the website
cd myblog
make render
```

### Argdown Integration

+ Install Argdown as project dependency (locally). (Using `nvm` as node manager.)

The dependency is defined in the `package.json` file. The following commands will install the correct version of Node.js and the needed dependencies:

```bash
# Pin node version: 
`echo "24" > .nvmrc`
nvm use
npm install 
```

I also use a locally (project-specific) installed version of the needed headless chrome via the defined `.puppeteerrc.cjs` (I had problems when using a globally installed `liascript`).
